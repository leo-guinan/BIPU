# Architecture

The architecture section is where we show the machinery instead of presenting the finished building as if it grew that way.

These notes cover the systems behind Build In Public University and the projects it studies: source structures, deployment boundaries, retrieval systems, measurement, and the decisions that keep the work reproducible.

The first notes examine the systems around Idea Nexus Ventures: a small static publishing system, a public Marvin guide, an ElevenLabs voice agent, a Chroma Cloud index behind a server-side credential boundary, and the product architectures that extend the humanpower thesis into hardware, communication, and networked writing.
