# LinkedIn Legibility Scoreboard

The Human Game Evals scoreboard tracks one downloaded LinkedIn profile PDF per participant per week.

[Open the live scoreboard](https://compete.metaspn.network/scoreboard)

## What is recorded

- the weekly PDF snapshot hash and capture week;
- the evaluator score and section scores;
- the participant's public LinkedIn profile URL;
- public metrics submitted with a source and capture date;
- week-over-week score and metric growth where two observations exist.

The uploaded PDF is retained privately for provenance. It is not publicly downloadable.

## What this does not claim

This scoreboard does not expose LinkedIn's ranking algorithm. It measures the surface we can observe: profile legibility, visible profile structure, and metrics a participant can legitimately read and submit. Missing metrics stay missing. A metric receipt is not proof of causality.

One participant can submit one snapshot per ISO week. Scores should be generated with the versioned rubric in the [Human Game Evals repository](https://github.com/Build-In-Public-University/human-game-evals).
